Lecture 04

ACM & IEEE Codes of Ethics — Deep Dive

Core principles, how to map real cases to the codes, and using codes as practical tools.

⏱ ~50 min📚 Module 4 of 30
◎

Learning Objectives

  • Recall the main principles of the ACM Code of Ethics (2018) and IEEE Code of Ethics.
  • Map a case study to specific code clauses.
  • Explain how codes support (but do not replace) professional judgment.
  • Identify situations where organizational pressure conflicts with code obligations.
📘

ACM Code — High-Level Structure

The ACM Code organizes principles around general ethical responsibilities, professional responsibilities, professional leadership principles, and compliance. Key themes include:

  • Contribute to society and to human well-being; avoid harm.
  • Be honest and trustworthy; respect privacy; honor confidentiality.
  • Respect the work required to produce new ideas and computing artifacts.
  • Maintain high standards of professional competence and conduct.
  • Design and implement systems that are robustly and usably secure.
Note
Always consult the official ACM and IEEE texts for formal citation and the latest wording. This lecture summarizes themes for teaching purposes.
📗

IEEE Code — Emphasis

IEEE’s code places strong weight on public safety, health, and welfare; honesty in statements; and treating persons fairly. For engineers working on safety-critical or infrastructure systems, these duties are central.

🗺️

Mapping a Case

Take a data-breach or biased-algorithm scenario. Ask: Which principles about harm, transparency, competence, and public interest are engaged? Which clauses would you cite if writing an internal ethics memo or external professional statement?
